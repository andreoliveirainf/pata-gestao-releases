# Pata Gestão — versões

Sistema de gestão para pet shops (vendas, estoque, banho e tosa, hotel e creche, financeiro, WhatsApp, NFC-e e NFS-e),
instalado no computador da loja.

Este repositório guarda **apenas os instaladores e o aviso de versão** usado pelo próprio sistema
(menu do usuário → Atualização). Não contém código-fonte.

- Página: https://patagestao.netlify.app
- Para atualizar: faça um backup, baixe o instalador da [última versão](../../releases/latest) e rode no computador servidor.
- Confira o arquivo: `Get-FileHash .\PetShop-Setup-*.exe` deve bater com o SHA-256 da release.
